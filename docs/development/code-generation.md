# 代码生成

根 POM 配置 `g2rain-generator-maven-plugin`，配置文件为 `codegen.properties`。

```bash
mvn g2rain-generator:generate
```

生成前：

1. 确认在仓库根目录执行，并使用专用开发数据库账户。
2. 核对配置中的表、包名和输出目录，不在日志或文档中泄露连接凭据。
3. 检查 Git 状态，避免覆盖未提交手写代码。

生成后必须人工校正：

- API 查询契约与 Biz 写入边界；
- 组织数据隔离、可信字段、状态机和事务；
- 唯一索引、逻辑删除、乐观锁和并发语义；
- OpenAPI 文案、错误码、测试和项目文档。

生成器输出不是领域事实来源，也不能自动证明架构合规。
